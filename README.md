# Startup website archive

This [`google-sites`](../../tree/google-sites) branch archives the website built for the startup exercise, as part of the *Technology Entrepreneurship* course.
For that course, the capstone project was a startup's product. Ours was fake-review detection using machine learning and NLP.

The site was made with and hosted on Google Sites.
What's here is an archive of the site's pages and images, recovered from Google Takeout and `wget`,
and then repaired commit by commit so that it works as a static site on GitHub Pages.

The goal is for this branch to be deployable.
If the Pages source is ever switched to `google-sites`, the site should work as it did on Google Sites.
